Recommended start: `docker compose up --build -d` to launch both the `defect-loupe-db` (PostgreSQL on host port 5433) and `defect-loupe-backend` (FastAPI on port 8000) services; API docs at `/docs`. For local development without containers: create a Python 3.11+ venv, install `requirements.txt`, run `docker compose up -d db` for the database, then `uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload`. Environment variables are loaded from `app/.env` (copied from `app/.env.example`) and include `DATABASE_URL`, `ACCESS_TOKEN_SECRET`, `REFRESH_TOKEN_SECRET`, and token expiry settings.

This root scope defines the containerized deployment surface and project scaffolding for a multi-tenant property inspection backend. The `Dockerfile` builds a `python:3.11-slim` image that installs pinned dependencies from `requirements.txt` and runs `uvicorn app.main:app` on port 8000. `docker-compose.yaml` orchestrates two services — an `ankane/pgvector` PostgreSQL 15 database (exposed on host port 5433) and the FastAPI backend — with a shared bridge network, named volume persistence, and a healthcheck-driven startup dependency so the backend waits until Postgres is ready. `requirements.txt` pins the runtime stack: FastAPI + Uvicorn, SQLAlchemy 2.0 ORM, psycopg2-binary driver, Alembic migrations, Pydantic v2, PyJWT, pwdlib[argon2] for password hashing, python-dotenv, and email-validator. `README.md` documents the relational data model (User/Inspector/Company/Client/Property/Inspection/InspectionArea/AreaPhoto/AreaObservation/Transcription), the intended `app/` package layout (`api/routes`, `api/dtos`, `services`, `repository`, `config`, `utils`), and both Docker Compose and local virtual-environment run instructions. `TASK_DECOMPOSITION.md` specifies a four-role team split (Auth/RBAC, Inspection Core, Media & Transcription, RAG/Vision/Reports) with explicit folder ownership, interface contracts, branching strategy, and sequential Alembic migration numbering to prevent schema conflicts.
